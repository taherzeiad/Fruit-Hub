Project Overview: Fruit Hub Mobile App
Fruit Hub is a vibrant and user-friendly mobile application designed to bring the freshest fruit salad combos directly to your doorstep. Built with a focus on a seamless user experience and modern UI/UX principles, the app caters to health-conscious individuals looking for a delicious and nutritious snack.

Key Features:
Intuitive Onboarding: A welcoming splash screen and interactive introduction that guide users through a quick authentication process.

Dynamic Combo Discovery: A rich home screen featuring "Recommended Combos" and categorizations like Hottest, Popular, and New Combo to help users find their perfect mix.

Detailed Product Insights: Each salad combo comes with a dedicated page detailing the ingredients (e.g., Red Quinoa, Lime, Honey) and easy quantity adjustment.

Seamless Basket Management: A sophisticated "My Basket" system allowing users to review orders, update quantities, and view real-time price calculations.

Flexible Checkout & Payment: Integrated multi-step checkout dialogs where users can input delivery details and choose between "Pay on Delivery" or "Pay with Card."

Real-time Order Tracking: A dedicated delivery status screen featuring a visual timeline—from order taking to preparation and final delivery—integrated with a map view for a transparent experience.

Technical Highlights:
Typography: Utilizes the premium Brandon Grotesque font family across various weights (Light, Regular, Medium, Bold, Black) to ensure a high-end, readable, and modern aesthetic.

Design System: A cohesive color palette featuring Primary Deep Purple for text and Vibrant Orange for primary actions, creating a energetic and appetizing feel.

User Experience: Smooth transitions, interactive bottom sheets for checkout, and clear visual feedback (congratulations screen) upon successful orders.

Summary Sentence (Short):
"Fruit Hub is a premium fruit salad delivery app that combines a healthy lifestyle with a sleek, modern mobile experience, offering personalized salad combos and real-time order tracking."
